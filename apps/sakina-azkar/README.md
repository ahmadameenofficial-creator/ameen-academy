# سكينة — مكتبة الأذكار

تطبيق عربي مستقل، موبايل فرست، بُني بـ Next.js 16 وReact 19 وTypeScript.

## التشغيل

```bash
cd apps/sakina-azkar
npm ci --cache /tmp/azkar-npm-cache
npm run dev
```

للإنتاج: `npm run build` ثم `npm run start`. لا يحتاج إلى حسابات أو قاعدة بيانات خارجية أو متغيرات سرية.

## ما يعمل

- حفظ جميع صفوف المصدر الأصلية (345)، مع 390 بطاقة بعد فصل النصوص المركبة وتخصيص مجموعتي أذكار الصلاة، في 137 تصنيفًا.
- عدادات مستقلة لكل صلاة، وأزرار عريضة بأرقام إنجليزية، ووضع فاتح وليلي وتلقائي محفوظ.
- بحث عربي يتجاهل التشكيل والتطويل واختلافات الألف، في التصنيفات والنصوص.
- عدّادات محدودة بالعدد الموجود في المصدر، وعدّادات حرة عند غياب العدد؛ تراجع وتصفير فردي وتصفير قسم بعد التأكيد.
- حفظ محلي بإصدار واضح، استعادة آمنة بعد تلف البيانات، وتزامن بين التبويبات.
- حفظ النصوص، النسخ والمشاركة، حجم الخط والتشكيل، إخفاء المكتمل، وضع تركيز.
- IBM Plex Sans Arabic مستضاف محليًا، RTL، أهداف لمس، تنقل بلوحة المفاتيح، احترام تقليل الحركة.
- حركة ظهور أثناء التمرير، استجابة أزرار، حركة العدّاد، وطباعة محسنة.

## هيكل المشروع

```text
data/upstream/         النسخة الأصلية وبيان إتاحة الاستخدام
scripts/import-data.py استيراد حتمي يعمل بدون اتصال
src/data/azkar.json    البيانات الناتجة، بمعرفات ثابتة
src/lib/catalog.ts    الفهارس والبحث
src/lib/progress.ts   منطق حالة القراءة، مستقل عن React والمتصفح
src/lib/reading-store.ts الحفظ والتزامن وواجهة useSyncExternalStore
src/components/       مكونات الواجهة، القارئ، البطاقات، المكتبة
src/app/              صفحات ثابتة وmetadata وحالات الخطأ
tests/                سلامة الاستيراد ومنطق الحالة واختبارات متصفح
```

## البيانات: الاكتمال وحدود الصحة

نُقلت **كل صفوف** المصدر `osamayy/azkar-db` عند commit:
`fbdfa017782c907fd0ca4ee2726060cbc527072f`.

ملف README الأصلي يصرّح بالسماح بالاستخدام والتعديل وإعادة التوزيع مجانًا، وقد حُفظ في `data/upstream/README.md`. لم يُنسخ الموقع الأصلي أو شروح إسلام بوك التحريرية.

- المصدر الأصلي يحتوي على 242 صفًا بلا مرجع و278 بلا عدد تكرار محدد. روجعت الصفوف الحرة جميعها لتصنيفها إلى أذكار وتعليمات وقراءة، واستخراج الأعداد الصريحة دون تحويل أعداد الفضائل إلى أهداف عدّ.
- النسخة المعروضة تحتوي على 237 عدادًا حرًا و23 بطاقة تعليمات؛ لا تدخل هذه البطاقات في إكمال الورد. ما زالت 246 بطاقة بلا مرجع مدوّن.
- الأصل محفوظ في `src/data/original-entries.json`، باستثناء تنظيف الأسطر والفراغات. فصل البطاقات وتصحيحات الأعداد موثّقة في `data/corrections.json`، ومراجعة الصفوف الحرة في `data/free-counter-audit.json`؛ ينفذها `scripts/curation.py` حتميًا.
- المصدر يحتوي على نصوص وتعليمات وبعض فقرات الفضائل؛ لذلك يُستخدم لفظ «نصوص» بدل الزعم بأن كل صف ذكر مفرد.
- **لا توجد مراجعة شرعية مستقلة للنصوص والتخريج.** يلزم تحقيق مختص قبل الادعاء أن المكتبة مُحققة. اكتمال هذا المصدر لا يعني كل الأذكار في السنة أو مطابقة كل أقسام إسلام بوك.
- البيانات ثابتة في هذه النسخة. ملفات الأصل وبصمة SHA256 وتقرير الاستيراد يسمحون بمراجعة أي تغيير.

خط IBM مرخص تحت SIL OFL؛ الرخصة محفوظة في `public/fonts/OFL.txt`.

## الحالة والخصوصية

البيانات الشخصية محفوظة في `localStorage` على نفس الجهاز، بدون تسجيل أو API للتقدم. تتجدد العدّادات عند تغير اليوم المحلي للجهاز؛ تبقى المحفوظات والإعدادات. تُفحص بداية اليوم عند الضغط، والتركيز على النافذة، وكل دقيقة. لا ينتقل الحفظ بين الأجهزة، وحذف بيانات المتصفح يمسحه. التخزين المعطّل يُعرض بوضوح.

الموقع لا يتضمن Service Worker؛ **لا نعد بإتاحة الاستخدام دون إنترنت**. النسخ والمشاركة يتطلبان HTTPS أو localhost ودعم المتصفح؛ تُعرض رسالة عند الفشل.
