# سكينة — مكتبة الأذكار

تطبيق عربي مستقل، موبايل فرست، بُني بـ Next.js 16 وReact 19 وTypeScript.

لفهرسة الموقع ومتابعة ظهور الأذكار في Google وإجابات AI، راجع [خطة البحث وربط Search Console](docs/search-growth.md). يتضمن التطبيق Sitemap وrobots وعناوين وأوصاف وروابط canonical وبيانات منظمة للمحتوى العام، مع عدم فهرسة صفحات المتابعة الشخصية.

## التشغيل

```bash
cd apps/sakina-azkar
npm ci --cache /tmp/azkar-npm-cache
npm run dev
```

للإنتاج: `npm run build` ثم `npm run start`. قراءة الأذكار والمحفظات والمتابعة الشخصية لا تحتاج إلى حسابات أو قاعدة بيانات. داشبورد المالك اختيارية وتحتاج قاعدة PostgreSQL وثلاثة متغيرات إعداد كما في [دليل الربط](docs/dashboard-setup.md).

## ما يعمل

- حفظ جميع صفوف المصدر الأصلية (345)، مع 390 بطاقة بعد فصل النصوص المركبة وتخصيص مجموعتي أذكار الصلاة، في 137 تصنيفًا.
- هوية بشعار سكينة، ووضع ليلي كحلي ببيبي بلو مصمت وتباين مرتفع؛ الأرقام والأزرار لا تعتمد على الشفافية.
- تطبيق ويب قابل للتثبيت: manifest، أيقونات Android وApple، اختصارات الأذكار، وتحديثات اختيارية تحفظ التقدم.
- عدادات مستقلة لكل صلاة، وأزرار عريضة بأرقام إنجليزية، ووضع فاتح وليلي وتلقائي محفوظ.
- متابعة شخصية أسبوعية وسجل أيام متتالية محفوظ محليًا، وتوضيح مختصر لاستخدام القارئ.
- داشبورد مالك محمية: جلسات وتفاعل وأقسام وأجهزة ودول ومصادر وتثبيت وسرعة Web Vitals، بفلاتر تاريخ ومقارنة وتصدير CSV.
- بحث عربي يتجاهل التشكيل والتطويل واختلافات الألف، في التصنيفات والنصوص.
- عدّادات محدودة بالعدد الموجود في المصدر، وعدّادات حرة عند غياب العدد؛ تراجع وتصفير فردي وتصفير قسم بعد التأكيد.
- حفظ محلي بإصدار واضح، استعادة آمنة بعد تلف البيانات، وتزامن بين التبويبات.
- حفظ النصوص، النسخ والمشاركة، حجم الخط والتشكيل، إخفاء المكتمل، وضع تركيز.
- IBM Plex Sans Arabic مستضاف محليًا، RTL، أهداف لمس، تنقل بلوحة المفاتيح، احترام تقليل الحركة.
- حركة ظهور أثناء التمرير، استجابة أزرار، حركة العدّاد، وطباعة محسنة.

## البيانات: الاكتمال وحدود الصحة

نُقلت **كل صفوف** المصدر `osamayy/azkar-db` عند commit:
`fbdfa017782c907fd0ca4ee2726060cbc527072f`.

ملف README الأصلي يصرّح بالسماح بالاستخدام والتعديل وإعادة التوزيع مجانًا، وقد حُفظ في `data/upstream/README.md`. لم يُنسخ الموقع الأصلي أو شروح إسلام بوك التحريرية.

- المصدر الأصلي يحتوي على 242 صفًا بلا مرجع و278 بلا عدد تكرار محدد. روجعت الصفوف الحرة جميعها لتصنيفها إلى أذكار وتعليمات وقراءة، واستخراج الأعداد الصريحة دون تحويل أعداد الفضائل إلى أهداف عدّ.
- النسخة المعروضة تحتوي على 237 عدادًا حرًا و23 بطاقة تعليمات؛ لا تدخل هذه البطاقات في إكمال الورد. ما زالت 246 بطاقة بلا مرجع مدوّن.
- الأصل محفوظ في `src/data/original-entries.json`، باستثناء تنظيف الأسطر والفراغات. فصل البطاقات وتصحيحات الأعداد موثّقة في `data/corrections.json`، ومراجعة الصفوف الحرة في `data/free-counter-audit.json`؛ ينفذها `scripts/curation.py` حتميًا.
- المصدر يحتوي على نصوص وتعليمات وبعض فقرات الفضائل؛ لذلك يُستخدم لفظ «نصوص» بدل الزعم بأن كل صف ذكر مفرد.
- **لا توجد مراجعة شرعية مستقلة للنصوص والتخريج.** يلزم تحقيق مختص قبل الادعاء أن المكتبة مُحققة. اكتمال هذا المصدر لا يعني كل الأذكار في السنة أو مطابقة كل أقسام إسلام بوك.
- البيانات ثابتة في هذه النسخة. ملفات الأصل وبصمة SHA256 وتقرير الاستيراد يسمحون بمراجعة أي تغيير.

خط IBM مرخص تحت SIL OFL؛ الرخصة محفوظة في `public/fonts/OFL.txt`.

## الحالة والخصوصية

البيانات الشخصية محفوظة في `localStorage` على نفس الجهاز، بدون تسجيل أو API للتقدم. تتجدد العدّادات عند تغير اليوم المحلي للجهاز؛ تبقى المحفوظات والإعدادات. تُفحص بداية اليوم عند الضغط، والتركيز على النافذة، وكل دقيقة. لا ينتقل الحفظ بين الأجهزة، وحذف بيانات المتصفح يمسحه. التخزين المعطّل يُعرض بوضوح.

سجل المتابعة الشخصية في `sakina:history:v1` مستقل عن عدادات اليوم والمحفوظات؛ لا يُرسل للخادم. يُسجل إتمام البطاقات ذات الأعداد المحددة لكل قسم/صلاة مرة واحدة في اليوم، ويحتفظ بآخر سنة.

تسجيل إحصائيات الاستخدام معطل ما لم تُربط الداشبورد، ويبدأ للزائر بعد السماح فقط. يحترم Do Not Track، ولا يرسل نصوص الأذكار أو المحفوظات أو استعلامات البحث أو عناوين IP. يرسل أحداثًا محددة مع جلسة عشوائية مؤقتة، ويدعم استعادة الدفعات غير المُقرّة بعد إعادة التحميل ومنع تكرارها على PostgreSQL. راجع حدود القياس في دليل الربط.

يتضمن بناء الإنتاج Service Worker بحزمة مرتبطة بإصدار البناء. يحفظ جميع صفحات التصنيفات والمكتبة والمحفظات والمصادر وملفات JavaScript وCSS والخطوط والشعار، ثم يُظهر «كل الأذكار جاهزة بدون إنترنت» بعد اكتمال الحفظ فقط. يلزم اتصال أول مرة لإتمام التحميل، وتوفير المتصفح مساحة للتخزين؛ يمكن للمتصفح حذف التخزين عند الحاجة. التحديث لا ينشط على التبويب المفتوح حتى يضغط المستخدم «تحديث التطبيق». لا يحذف التحديث `localStorage` أو عدادات القراءة. التطوير لا يسجّل Service Worker.

لتثبيت التطبيق على iPhone: Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية. على Android أو الكمبيوتر يُستخدم زر التثبيت أو قائمة المتصفح. النسخ والمشاركة يتطلبان HTTPS أو localhost ودعم المتصفح؛ تُعرض رسالة عند الفشل.

## التحقق

جلسة المئة الجديدة للصباح والمساء: [التصميم، الحفظ، والوصول](docs/hundred-session.md). تشارك عدّادات البطاقات وتعمل دون اتصال؛ إعدادات الاهتزاز والشاشة اختيارية.

```bash
npm run data:import
npm run test
npm run typecheck
npm run lint
npm run build
npx playwright install chromium
npm run test:e2e
```

اختبارات المتصفح تستخدم بناء الإنتاج على المنفذ 3100، وتغطي الديسكتوب والموبايل والبحث والعدّ والحفظ والاستعادة والتزامن والتقليل من الحركة وعدم تجاوز عرض الشاشة.
