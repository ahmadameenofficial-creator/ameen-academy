# تحقق النسخة الحالية

التحقق على بناء الإنتاج، وليس خادم التطوير فقط.

| التحقق | النتيجة |
|---|---|
| استيراد المصدر | حفظ 345/345 صفًا أصليًا، 390 بطاقة بعد الفصل، 137 تصنيفًا |
| اختبارات البيانات ومنطق الحالة | 16 ناجحة، 0 فاشلة، 0 متجاوزة |
| اختبارات المتصفح | 24 ناجحة، 0 فاشلة، 0 متجاوزة |
| بناء الإنتاج | ناجح، 144 صفحة ثابتة إجمالًا |
| فتح جميع التصنيفات | جميع التصنيفات 137 ترجع HTTP 200 |
| تصنيف غير موجود | HTTP 404 حقيقي |
| TypeScript | ناجح |
| ESLint | ناجح |
| فحص Axe للصفحات الأساسية | لا مخالفات مكتشفة لقواعد WCAG A/AA المختارة |

اختبارات المتصفح تُنفذ على Chrome للديسكتوب وعلى حجم موبايل، وتشمل فحص 360px وتقليل الحركة. فُحص البحث بالتشكيل وبدونه، العدادات المحدودة والتراجع، حفظ التقدم بعد إعادة التحميل، المحفوظات، التزامن بين التبويبات، استعادة التخزين التالف، حجم الخط، التركيز، التصفير المؤكد، والبحث بمعاملات URL مكررة.

فُحصت مجموعتا أذكار الصلاة: أعداد التسبيح والتحميد والتكبير مستقلة، والفجر والمغرب متشابهان مع دعاء العلم الخاص بالفجر، والتصفير والحفظ مستقلان لكل صلاة. فُحصت الأرقام الإنجليزية، والأزرار بارتفاع 96px على الموبايل، وفصل البطاقات، والعدادات الحرة، وعدم تحويل التعليمات إلى عدادات. روجعت بصريًا بطاقات الصلاة في الوضعين الفاتح والليلي.

فحص الوصول الآلي لا يُغني عن تجربة بشرية بقارئات الشاشة. لم يُختبر Safari أو Firefox. هذه النتائج تخص بناء الإنتاج المحلي؛ تُراجع حالة نشر التحديث بشكل منفصل.

**التحقق البرمجي لا يساوي تحقيق النصوص شرعيًا.** روجعت جميع الصفوف الأصلية البالغ عددها 278 التي كانت بلا هدف عدّ، وسُجلت التصحيحات في ملفات التدقيق. النسخة المعروضة تحتوي على 237 عدادًا حرًا و23 بطاقة تعليمات؛ لا تُختلق لها أهداف عدّ. أذكار الصلاة المصححة مرتبطة بمراجع صحيح مسلم وحصن المسلم؛ لم يُجر تحقيق شرعي مستقل لجميع نصوص المكتبة.
