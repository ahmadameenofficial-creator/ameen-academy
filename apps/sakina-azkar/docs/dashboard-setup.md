# تشغيل داشبورد سكينة

الرابط بعد نشر الكود: `https://azkar.ameen.academy/dashboard`.

## إنشاء قاعدة Neon مجانية

1. افتح https://console.neon.tech وسجّل بحسابك، واختر خطة Free.
2. أنشئ مشروعًا باسم `sakina-analytics`. اختر منطقة Frankfurt إذا كانت متاحة؛ لا تستخدم قاعدة أمين أكاديمي.
3. افتح **Connect** واختر اتصال **Pooled connection**. انسخ Connection string كما هي؛ اسم قاعدة `neondb` الافتراضي مناسب.
4. افتح مشروع `ameen-academy-azkar` في Vercel، ثم **Settings → Environment Variables**.
5. أضف `SAKINA_DATABASE_URL`، وضع Connection string في القيمة، وحدد Production.
6. أضف `DASHBOARD_PASSWORD` بكلمة قوية مختلفة عن حساباتك، بطول 16 حرفًا على الأقل.
7. أضف `DASHBOARD_SESSION_SECRET` بقيمة عشوائية بطول 32 حرفًا على الأقل. يمكن توليد كلمتي الإدارة بتشغيل `node scripts/generate-dashboard-secrets.mjs` من مجلد التطبيق. السكربت يكتب ملفًا خاصًا تجاهله Git، ولا يطبع القيم في السجل.
8. افتح **Deployments → Create Deployment** واختر `main`. لا تضع أي قيمة في متغير يبدأ بـ `NEXT_PUBLIC_`، ولا تشارك Connection string في محادثة عامة.
9. افتح `/dashboard` وأدخل كلمة مرور الإدارة. يُنشئ التطبيق جداول مستقلة في schema باسم `sakina_analytics` تلقائيًا عند أول اتصال.
10. لاختبار التسجيل: افتح الموقع في تبويب آخر، واسمح بالإحصائيات، وافتح قسمًا واضغط عداده ثم انتقل لصفحة أخرى؛ ارجع للداشبورد واضغط «تحديث الآن».

إذا ظهر تنبيه «غير مفعلة»، راجع أسماء المتغيرات وأطوال كلمات الإدارة ثم أعد النشر. إذا تعذّر الاتصال، راجع Connection string ووجود `sslmode=require` وصلاحية قاعدة Neon. لا تستخدم ملف SQLite أو تخزين ملفات Vercel للإحصائيات.

الخطة المجانية بداية مناسبة، وليست ضمانًا لتخزين أو تشغيل غير محدود. راقب Storage وCompute في Neon؛ لا تحتاج تفعيل خطة مدفوعة للبدء. كفاءة التجميع في العميل وحد التخزين 90 يومًا تقلل حجم البيانات، لكن زيادة الجمهور قد تستلزم تجميعًا يوميًا أو خطة أكبر. راجع حدود وأسعار Neon الرسمية قبل الترقية. عند بدء بيع رعايات، راجع أيضًا شروط الاستضافة الحالية للاستخدام التجاري.

## ما الذي تقيسه اللوحة؟

- جلسات مجهولة، مشاهدات صفحات، معدل التفاعل، ووقت ظهور الصفحة المقدّر.
- مقارنة بالفترة السابقة بطول مماثل، حتى 90 يومًا، بتوقيت القاهرة مع مراعاة التوقيت الصيفي.
- ضغطات العدّ وبطاقات وصلت لهدف التكرار، والأقسام الأكثر استخدامًا.
- الأجهزة والمتصفحات وأنظمة التشغيل والدول ومصادر الزيارات.
- تثبيت يُبلّغ عنه المتصفح، والنسخ والمشاركة، وعودة اتصال مرصودة بعد العمل بدون إنترنت.
- Web Vitals: ‏LCP وINP وCLS عند المئين 75، وأعداد أخطاء الواجهة، دون نصوص الأخطاء أو stack traces.
- تحديث يدوي أو تلقائي كل 30 ثانية، وتصدير CSV محمي.

البيانات تبدأ عند تفعيل التسجيل وموافقة الزائر. لا تظهر زيارات تاريخية لم تكن مسجلة. الجلسات ليست عدد أشخاص فريدين؛ Session Storage يحتفظ بمعرّف عشوائي لجلسة التصفح، ثم يتغير بعد 30 دقيقة انقطاع. الجلسات في تبويبات مستقلة قد تُحتسب منفصلة. «عائدة» تعني أن المتصفح سجّل زيارة سابقة بعد الموافقة؛ لا يوجد تعقب مستمر عبر الأجهزة.

قد تقل الأرقام بسبب رفض التسجيل أو حجب التتبع أو تعطل الشبكة. country تقدير من Vercel على مستوى الدولة؛ لا تُخزَّن عناوين IP، أو أسماء، أو استعلامات بحث، أو نصوص الأذكار، أو المحفوظات. تُستخدم بصمة HMAC قصيرة الغرض لعناوين الشبكة لتقييد الطلبات ومحاولات الدخول، ولا تظهر في الداشبورد. Do Not Track يمنع التسجيل في العميل.

أحداث التثبيت اليدوي على iPhone قد لا تُبلّغها واجهة المتصفح. إحصاء «عودة الاتصال» ليس عددًا كاملًا لجلسات offline. Web Vitals تعتمد على المتصفح والموافقة، وقد لا تتوفر في بعض الزيارات.

## البنية والتحقق

`analytics-contract.ts` يحدد الأحداث المسموح بها وأعدادها وفتراتها؛ `analytics-client.ts` يجمع الضغطات في دفعات صغيرة؛ `analytics-db.ts` يخزن PostgreSQL ويحسب التقارير؛ `dashboard-auth.ts` يحمي جلسة الإدارة. API التسجيل لا يمرر قيمًا حرة للـSQL، ومعرّفات الأحداث تمنع تكرار إرسال الدفعة. إنشاء الجداول وتغيير الحالة يتمان داخل معاملات، وقفل advisory يمنع تعارض التهيئة من أكثر من عملية serverless. الاتصال يستخدم pool صغيرًا ويدعم Neon Pooled connection.

جلسة الإدارة موقعة، مدتها 8 ساعات، وكعكتها HttpOnly وSameSite=Strict وSecure على الدومين. محاولات الدخول محدودة، وPOST يتطلب Origin مطابقًا للـHost الخارجي. التقارير والتصدير محميان، وService Worker يتجاهل الداشبورد وكل API. صفحات الإدارة وبيانات التقارير لا تدخل cache الخاص بالمكتبة؛ ملفات الواجهة العامة لا تحتوي أسرار الإدارة.

الدفعات غير المُقرّة تحفظ مؤقتًا في Session Storage بعد الموافقة، مع أسماء أحداث ومسارات معروفة فقط، بحد 80 حدثًا و24 ساعة. يحتفظ كل حدث بجلسة حدوثه الأصلية حتى بعد إعادة التحميل؛ PostgreSQL يمنع ازدواج نفس ID عند إعادة الإرسال. الضغطات غير المرسلة تُجمع حسب القسم لتقليل الكتابة والتكلفة. إلغاء الموافقة يمسح الدفعات المعلقة.

لتغيير كلمة الإدارة أو إبطال جلساتها كلها: غيّر `DASHBOARD_PASSWORD` و`DASHBOARD_SESSION_SECRET` ثم أعد النشر. لا تُحفظ كلمة المرور في قاعدة البيانات.

```bash
npm run test
npm run test:analytics-integration  # قاعدة اختبار مستقلة في SAKINA_DATABASE_URL
npm run build
npm run check:deployment
npm run test:e2e                 # يحتاج بيانات اختبار الإدارة لتشغيل اختبارات الداشبورد
```

الإشعارات تحتاج خدمة Web Push ومفاتيح VAPID ومجدولًا على السيرفر؛ لم تُفعّل في هذه النسخة. لا توجد حاليًا إعلانات أو مدفوعات أو إحصائيات رعايات. يمكن إضافة هذه الخدمات مستقلة بعد اختيار مزوّدها والرعاة.
